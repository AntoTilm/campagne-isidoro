# Mots-clés cachés de la recherche
#
# Ces mots ne s'affichent nulle part : ils aident seulement la recherche (touche /) à trouver la bonne page.
#
#   [page.html#ancre] @isidoro      les lignes suivantes, séparées par des virgules, s'attachent à cette section
#                                   pour ce savoir (@isidoro, @theodoric, @mj, ou rien pour la partie commune).
#                                   Les mots respectent le point de vue : en vue Isidoro, un mot-clé @theodoric
#                                   ne fait rien apparaître.
#   = mot, variante, synonyme       une recherche sur l'un trouve aussi les autres. Réservé aux orthographes,
#                                   fautes de dictée et termes anglais : jamais de révélation (pas « Pierrot = lycanthrope »).
#
# Un bloc se termine par une ligne vide. Les accents et majuscules ne comptent pas.
