Comment lire ce registre

Le point de vue

Deux tables jouent la même campagne : celle d'Isidoro et, avant elle, celle de Théodoric. Le sélecteur Point de vue, en haut de chaque page, n'affiche que ce que sait le personnage choisi. Rien n'est jamais supprimé : la vue Tout montre l'ensemble, avec la provenance de chaque information.

  • Isidoro : sa table, son journal, ses visions
  • Théodoric : l'ancienne table et ses documents
  • Monde : le MJ, le hors-jeu, les recoupements
  • Les deux personnages

La vue par défaut est celle d'Isidoro. La touche / ouvre la recherche, qui respecte elle aussi le point de vue.

Les encadrés

Isidoro distingue toujours ce qu'il a vu de ce qu'on lui a dit. La forme d'un encadré indique la nature de l'information.

  • Fait jouéCe que vivent les personnages autour de la table. Texte courant, sans encadré.
  • VisionUn futur possible vu dans les vasques du Cœur Radieux. Il peut ne jamais se réaliser.
  • Hors-jeuCe que savent les joueurs mais pas les personnages : l'autre table, l'ancienne campagne.
  • RapportéUn document écrit par quelqu'un d'autre, souvent un ennemi. Chaque pièce a sa fiche de provenance.
